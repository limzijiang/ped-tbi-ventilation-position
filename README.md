# 小兒疑似頭部外傷：抬高床頭 · 避免過度換氣 · EtCO₂ 監測

EMT / EMT-P 教學簡報（單一 HTML 檔，離線可開，可直接列印成 PDF）。

- 線上版：https://limzijiang.github.io/ped-tbi-ventilation-position/
- 內容：先呈現成人證據力，再對照小兒證據，最後給可記住的現場口訣與 OSCE 情境。
- 實證來源：BTF 院前指引 3rd ed（2023）、BTF 小兒重度 TBI 指引 3rd ed（2019）、EPIC / EPIC4Kids、Cochrane、2024–2025 meta-analyses。關鍵數字皆回原文核對（見簡報「數字查核」頁）。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 可直接開啟的完整簡報（圖片已內嵌為 data URI） |
| `deck_src.html` | 編輯用原始檔，圖片以 `__IMG_*__` token 佔位 |
| `build.py` | 把 `fig/` 的圖內嵌進 `deck_src.html` → 產生 `index.html` |
| `fig/` | 期刊原圖與裁切合成圖 |

改內容請編輯 `deck_src.html`，然後：

```bash
python3 build.py
```
